# Factories (patrón Factory)

Crean objetos de dominio ya validados, ocultando reglas de construcción repetitivas.

- `MovimientoFactory`: ingresos, egresos, ingreso por pago y reversión de pago.
- `PagoFactory`: pagos completados.
- `ContratoFactory`: contrato a partir de un plan (calcula fecha fin y precio).
